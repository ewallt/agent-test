NotebookLM CLI

Command reference for nlm — the notebooklm-mcp-cli tool used to automate notebook creation, source management, and artifact generation.

⚡ The Basics

Always use the PYTHONIOENCODING prefix. Missing it causes UnicodeEncodeError on Windows. Every command must be prefixed:

PYTHONIOENCODING=utf-8 nlm <command> [options]

Version: notebooklm-mcp-cli v0.3.2  ·  Account: ewalltom@gmail.com

Sessions last ~20 minutes. Check auth before starting a run, and re-login if commands start failing mid-run.

# Check auth status PYTHONIOENCODING=utf-8 nlm auth status # Login if expired PYTHONIOENCODING=utf-8 nlm login

Get AI-friendly docs for any command by appending --ai. Useful for discovering option details — but verify against actual --help output, as the AI docs can contain inaccuracies (e.g., slide deck format was incorrectly listed as .txt; it is PDF).

PYTHONIOENCODING=utf-8 nlm --ai > ai-docs.txt

📋 Command Groups

notebook Create and manage notebooks
nlm notebook create "title" Create a new notebook. Capture the returned notebook ID.
nlm notebook list List all notebooks with their IDs.
nlm notebook get <id> Get details for a specific notebook.
nlm notebook query <id> "question" Chat with notebook sources. Used in research-based pattern to inform Claude-written sources.
nlm notebook delete <id> Permanently delete a notebook.
source Add and manage knowledge sources
nlm source add <id> --file <path> --title "Title" --wait Always use --wait — blocks until the source is processed. Upload order matters: knowledge base first, then slide manifest, then web app doc.
nlm source list <id> List sources in a notebook. Use to verify count after research import.
nlm source get <id> <source-id> Get details for a specific source.
nlm source content <id> <source-id> Get raw content from a source (no AI processing).
nlm source delete <id> <source-id> Permanently delete a source.
research Discover and import sources from the web
nlm research start "query" --notebook-id <id> --mode fast Start a research task. Returns a task ID for status polling.
nlm research status <id> --max-wait 300 Poll until research completes (waits up to 300 seconds).
nlm research import <notebook-id> <task-id> Import discovered sources into the notebook. May time out but still succeed — verify with nlm source list before retrying.
video / slides / infographic / audio Generate NotebookLM-native artifacts
nlm video create <id> --style <style> --confirm Create a video overview. Always include --confirm.
nlm slides create <id> --confirm Create a slide deck. Downloads as PDF.
nlm infographic create <id> --orientation <o> --detail <d> --confirm Create an infographic. Downloads as PNG. Options: orientation (landscape/portrait/square), detail (concise/standard/detailed), focus (free text).
nlm audio create <id> --confirm Create an audio overview (podcast format).
studio Monitor artifact generation status
nlm studio status <id> List all studio artifacts for a notebook and their status. Poll this after triggering artifact generation. Look for completed.
nlm studio delete <id> <artifact-id> Delete a studio artifact permanently.
download Download completed artifacts
nlm download slide-deck <id> --output <path>.pdf Download slide deck as PDF.
nlm download infographic <id> --output <path>.png Download infographic as PNG. No artifact ID needed — fetches the latest.
nlm download audio <id> --output <path>.mp3 Download audio overview.
nlm download video <id> Video download via CLI is unreliable — note the artifact ID and access via NLM UI instead.
share Notebook sharing and access control
nlm share public <id> Enable public link access (anyone with link can view). Run at wrap-up.
nlm share private <id> Disable public access.
nlm share status <id> Show current sharing status and collaborators.
report / quiz / flashcards / mindmap / data-table Additional NLM-native artifact types
nlm report create <id> --confirm Create a report. Downloads as Markdown.
nlm quiz create <id> --confirm Create a quiz from notebook sources.
nlm flashcards create <id> --confirm Create flashcards from notebook sources.
nlm mindmap create <id> --confirm Create a mind map. Downloads as JSON.
nlm data-table create <id> --confirm Create a data table. Downloads as CSV.

🔁 Typical Run Sequence

# 1. Auth check PYTHONIOENCODING=utf-8 nlm auth status # 2. Create notebook PYTHONIOENCODING=utf-8 nlm notebook create "Topic Title" # → capture notebook ID # 3. Upload sources (always use --wait) PYTHONIOENCODING=utf-8 nlm source add <id> --file staging/knowledge.txt --title "Topic" --wait PYTHONIOENCODING=utf-8 nlm source add <id> --file slideshows/topic.md --title "Slide Manifest" --wait # 4. Generate artifacts PYTHONIOENCODING=utf-8 nlm video create <id> --style cinematic --confirm PYTHONIOENCODING=utf-8 nlm slides create <id> --confirm PYTHONIOENCODING=utf-8 nlm infographic create <id> --orientation landscape --detail standard --confirm # 5. Poll until completed PYTHONIOENCODING=utf-8 nlm studio status <id> # 6. Download PYTHONIOENCODING=utf-8 nlm download slide-deck <id> --output artifacts/topic/topic-slides.pdf PYTHONIOENCODING=utf-8 nlm download infographic <id> --output artifacts/topic/infographic.png # 7. Share PYTHONIOENCODING=utf-8 nlm share public <id>

⚠️ Known Gotchas

Always use PYTHONIOENCODING=utf-8 Missing this prefix causes UnicodeEncodeError. Every single command needs it.
Always use --wait when adding sources Without it, the source may not be processed before artifact generation begins.
Research import may time out but still succeed Check source count with nlm source list <id> before retrying an import.
Video CLI download is unreliable Note the artifact ID from nlm studio status and download via the NotebookLM UI instead.
Session expires in ~20 minutes Re-run nlm login if commands start failing mid-run.
--ai docs can be inaccurate The --ai flag is useful for discovery but verify against --help. Known error: slide deck listed as .txt — it is PDF.
Slide deck vs. Gemini slide manifest — these are different things nlm slides create generates a NotebookLM-native PDF deck. The Gemini slide manifest is a markdown file Claude writes and uploads as a source — Gemini then reads the notebook sources and builds slides from it.
