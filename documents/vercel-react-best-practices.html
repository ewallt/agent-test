Task Wrap-Up Orchestrator

A skill designed specifically to prevent context loss at the end of a coding session. Its purpose is to act as an automated end-of-session checklist — closing things out in a disciplined way rather than leaving the session scattered across terminal history and unstaged files.

  • Cognitive review and memory — Reviews session history to identify lessons learned and recurring mistakes made by the AI.
  • Persistent documentation — Updates memory files such as CLAUDE.md so future sessions preserve architectural decisions and avoid repeating errors.
  • Repository management — Checks local file changes, catches uncommitted work, generates standardized Git commits, and pushes changes.

This turns the AI from a stateless assistant into a continuous collaborator that builds compounding knowledge over time.

npx skills add charon-fan/agent-playbook --skill wrap-up
