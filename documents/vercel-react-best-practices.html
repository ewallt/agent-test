Task Wrap-Up Orchestrator

There is a skill designed specifically to prevent context loss at the end of a coding session: the Task Wrap-Up Orchestrator, often called Task Wrap-Up.

Its purpose is to act as an automated end-of-session checklist. Instead of leaving the session scattered across terminal history and unstaged files, it helps close things out in a disciplined way.

  • Cognitive review and memory — It reviews the session history to identify lessons learned and recurring mistakes made by the AI.
  • Persistent documentation — It updates memory files such as CLAUDE.md so future sessions preserve architectural decisions and avoid repeating the same errors.
  • Repository management — It checks local file changes, catches uncommitted work, generates standardized Git commits, and pushes the changes.

This turns the AI from a stateless assistant into more of a continuous collaborator that can build compounding knowledge over time.

Install command:

npx skills add charon-fan/agent-playbook --skill wrap-up
