Claude Code Loading Tips

These tips appear in the spinner while Claude Code is working. There are 32 built-in tips, plus a bonus tip that appears after 30+ seconds of waiting.

Getting Started

  1. Start with small features or bug fixes, tell Claude to propose a plan, and verify its suggested edits
  2. Ask Claude to create a todo list when working on complex tasks to track progress and remain on track
  3. Hit Enter to queue up additional messages while Claude is working
  4. Send messages to Claude while it works to steer Claude in real-time

Keyboard & Input

  1. Press Shift+Enter to send a multi-line message (Option+Enter on Mac Terminal)
  2. Run /terminal-setup to enable Shift+Enter for new lines
  3. Double-tap Esc to rewind the conversation to a previous point in time
  4. Double-tap Esc to rewind the code and/or conversation to a previous point in time
  5. Paste images into Claude Code using Ctrl+V (not Cmd+V!)
  6. Did you know you can drag and drop image files into your terminal?

Commands

  1. Use /config to change your default permission mode (including Plan Mode)
  2. Use /memory to view and manage Claude memory
  3. Use /theme to change the color theme
  4. Use /statusline to set up a custom status line that will display beneath the input box
  5. Use /permissions to pre-approve and pre-deny bash, edit, and MCP tools
  6. Use /agents to optimize specific tasks — e.g. Software Architect, Code Writer, Code Reviewer
  7. Use /feedback to help us improve!
  8. Name your conversations with /rename to find them easily in /resume later
  9. Run claude --continue or claude --resume to resume a conversation

Plan Mode

  1. Use Plan Mode to prepare for a complex request before making changes (press the cycle key twice to enable)
  2. Use /config to change your default permission mode (including Plan Mode)

Skills & Agents

  1. Create skills by adding .md files to .claude/skills/ in your project, or ~/.claude/skills/ for skills that work in any project
  2. Use --agent <agent_name> to directly start a conversation with a subagent

IDE & Integrations

  1. Connect Claude to your IDE · /ide
  2. Run /install-github-app to tag @claude right from your GitHub issues and PRs
  3. Run /install-slack-app to use Claude in Slack

Advanced

  1. Use git worktrees to run multiple Claude sessions in parallel
  2. Try setting environment variable COLORTERM=truecolor for richer colors

Access Claude Code Anywhere

  1. Run Claude Code locally or remotely using the Claude desktop app: clau.de/desktop
  2. Use Claude Code on the web: clau.de/web
  3. /mobile to use Claude Code from the Claude app on your phone

Bonus Tip (shown after 30+ seconds)

  1. Use /btw to ask a quick side question without interrupting Claude's current work
