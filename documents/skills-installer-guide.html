Reference Guide

Agent Skills Installer

How the npx skills CLI works — installing reusable AI agent capabilities from GitHub repositories across multiple coding agents.

? What Is This

Skills are reusable instruction packages for AI coding agents — Claude Code, Cursor, Copilot, and others. A skill tells the agent how to handle a specific domain: Remotion video creation, finding other skills, building notebooks, etc.

The npx skills CLI (from skills.sh) installs skills from public GitHub repositories into your project or global agent configuration. Once installed, the agent automatically loads the skill when relevant tasks come up.

Think of skills like plugins: they extend what the agent knows how to do without you having to explain it from scratch each session.

⌨ The Command

# Install a skill from a GitHub repo npx skills add remotion-dev/skills # General pattern npx skills add <github-owner>/<repo-name>

The CLI fetches the repo, detects which skills it contains, runs security checks, and installs them — either project-scoped (into .agents/skills/) or globally. It uses a symlink so the skill stays in sync if the source repo updates.

→ Installation Flow

1
Clone the repo The CLI fetches the GitHub repository containing the skill(s).
2
Detect skills It scans the repo for skill definition files and lists what it found.
3
Security assessment Three automated checks run: Gen AI safety scan, Socket supply-chain analysis, and Snyk vulnerability scan. Results are shown before you confirm.
4
Choose scope and method Project (local to this repo) or global. Symlink (recommended — stays current) or copy.
5
Install For Claude Code, the skill lands in .agents/skills/<skill-name>/ in your project, symlinked into Claude's skill directory.

Note on Snyk "Med Risk": This rating applies to the skill package itself, not its content. It typically flags missing security metadata (no license, no maintainer policy) rather than actual vulnerabilities in the skill instructions. Both skills above are plain instruction text — they contain no executable code of their own.

🔒 Security Checks

CheckWhat It TestsWhat to Watch For
Gen AI-generated content safety scan — looks for prompt injection, jailbreak attempts, or malicious instructions embedded in the skill. Anything other than "Safe" — a skill with hidden instructions could manipulate the agent.
Socket Supply-chain analysis — checks for known malicious packages or suspicious dependencies if the skill includes scripts. Any alerts. Zero alerts means no known supply-chain flags.
Snyk Vulnerability scan — checks for known CVEs and security policy metadata. "High Risk" is a red flag. "Med Risk" on instruction-only skills is usually a metadata gap, not a real vulnerability.

📁 Where Skills Live

Project-scoped (what was installed here):

agent-test/ .agents/ skills/ remotion-best-practices/ ← symlinked → Claude Code find-skills/ ← symlinked → Claude Code

Globally installed skills (manually written or installed via other means) live at:

~/.claude/skills/ shutdown/ ← custom skill whiteboard-explainer/ remotion-narrated-slides/ find-skills/ ← custom replacement version ... etc

When Claude Code starts, it loads both locations. Project-scoped skills take precedence over global ones with the same name.
