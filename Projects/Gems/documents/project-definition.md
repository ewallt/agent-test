# Gems — Project Definition

Custom Google Gemini personas (Gems), each with a system prompt and one or more knowledge files. Each Gem lives in its own subfolder containing its prompt and JSX reference file.

## Skills
- `gems-builder` — builds and updates Gems (system prompt + knowledge file). Not yet implemented.

## Gems

### WarRoom
A battle analyst Gem that generates structured military engagement reports as 5-tab React apps in Canvas.

- `Projects/Gems/warroom/` — gem-prompt.md + warroom-reference.jsx
