Edge TTS

Free, keyless narration generation for Behold Your God illustration videos — powered by Microsoft Edge neural voices.

💡 Why We Switched

ElevenLabs (before)

  • 10,000 characters/month free

  • ~7 videos before hitting limit
  • Requires API key
  • Full BYG series needs ~2 months

Edge TTS (now)

  • Unlimited — no quota
  • No API key required
  • No account needed
  • Free forever
  • Comparable voice quality
Note ElevenLabs audio already generated (NuclearPlant slides, GodNotCriminal slides 1–3) is kept as-is. No need to regenerate existing files.

⚙️ One-Time Setup

Install the Python package. Only needs to be done once per machine.

pip install edge-tts

Verify it installed correctly:

python -c "import edge_tts; print('edge-tts ready')"

🎙️ Generating Audio

Each BYG composition has its own generation script in scripts/. Run from the simple-narrated-slides project root.

Illustration 02 — God Is Not a Criminal

cd C:\Users\tomew\Documents\agent-test\Projects\Remotion\simple-narrated-slides node scripts/generate-god-not-criminal-audio-edge.mjs

The script skips files that already exist. To force regenerate everything:

node scripts/generate-god-not-criminal-audio-edge.mjs --force

What the script produces

public/audio/god-not-criminal/ title.mp3 slide-1.mp3 slide-2.mp3 slide-3.mp3 slide-4.mp3 src/god-not-criminal-durations.ts ← auto-updated with real durations

After the script runs, the Remotion dev server hot-reloads automatically with the correct timing.

➕ Adding to a New Composition

  1. Copy the generation script
    cp scripts/generate-god-not-criminal-audio-edge.mjs scripts/generate-{slug}-audio-edge.mjs
  2. Edit the NARRATIONS array — replace title and slide narration text with the new composition's content.
  3. Update OUTPUT_DIR — change "public/audio/god-not-criminal" to "public/audio/{slug}".
  4. Update the durations file path and export name — change god-not-criminal-durations and GOD_NOT_CRIMINAL_DURATIONS_S to match the new slug.
  5. Create the durations placeholder — copy src/god-not-criminal-durations.ts, rename it, update the export name and comment.
  6. Run the script — generates all MP3s and writes real durations.

🔧 Technical Notes

Python packageedge-tts v7.2.8+
Output formatMP3 (128kbps)
Duration estimatefile size ÷ 128kbps × 0.974 correction factor
Windows escapingScript writes a temp .py file per clip to avoid shell quoting issues — safe to re-run
Skip logicExisting files are skipped by default; use --force to regenerate all
Rate adjustmentPass rate="-10%" to Communicate() to slow down delivery

🩺 Troubleshooting

Script runs but file not created

Verify Python is on your PATH:

python --version

Also check the temp _tmp_*.py file wasn't left behind in the audio folder — delete it and retry.

Durations seem wrong in the video

Re-run the generation script (even with --force if needed) to refresh *-durations.ts. The dev server hot-reloads automatically.

Audio sounds too fast

Edit the script and add a rate parameter to the Communicate call:

c = edge_tts.Communicate(text, voice, rate="-10%")
