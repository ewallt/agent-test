Project Reference

Behold Your God

Video series and companion web app based on F.T. Wright's Behold Your God — 11 animated illustration videos paired with an interactive study app.

📖 What the Project Is

BYG is two things built together. First, a series of 11 short animated videos — one per illustration from Wright's book. Each video takes a concrete story or analogy Wright uses and renders it as an animated SVG doodle composition: dark background, spring-animated drawings, per-bullet reveals. Second, a companion web app that ties the videos together with interactive study tools.

The videos are built in Remotion inside the simple-narrated-slides project (studio at localhost:3001). Each illustration becomes a .tsx file, rendered to MP4, and deployed with a wrapper HTML page to gh-pages.

The web app is a single bundled HTML file (behold-your-god.html) with four tabs: Illustrations, Explorer, Flashcards, and Quotes. It lives in the NotebookLM apps folder and is also deployed to gh-pages.

🌐 The Web App

File: Projects/NotebookLM/ephemeral-notebook/apps/behold-your-god.html — currently v1.1. A single bundled HTML file with four top-level tabs.

  • Illustrations — Lists all 11 videos with status badges (▶ Watch or Coming Attraction). Links to wrapper pages for completed videos. This is the only tab driven by the illustration list.
  • Explorer — AI-generated knowledge explorer and quiz. Runs off embedded content (standalone, not linked to the illustrations list).
  • Flashcards — Card-based review of key concepts. Runs off embedded content.
  • Quotes — 15 key quotes from the book organized by theme, with proper attribution (F.T. Wright originals and Ellen White sources). Added in v1.1.
Deploying Use the gh-pages-deploy skill to push behold-your-god.html to gh-pages. When a new video is completed, also deploy the MP4 and wrapper HTML to notebooklm/byg-{slug}/.

Version bumping Always use a new versioned filename for MP4 updates (e.g. -v2.mp4). CDN caches the old file indefinitely — a new filename is the only reliable way to bust the cache.

⚙️ Workflow — Building a New Illustration Video

1
Read the notes Open illustrations/{nn}-{slug}/notes.md — it contains the illustration story, the theological argument, bullet beats with narration text, and doodle concepts for each beat.
2
Create the TSX file Copy NuclearPlant.tsx as the template. Adapt for the new illustration's content, doodle components, and bullet sequence. Save as Projects/Remotion/simple-narrated-slides/src/{Name}.tsx.
3
Register in Root.tsx Add the new composition to simple-narrated-slides/src/Root.tsx.
4
Generate audio Copy scripts/generate-god-not-criminal-audio-edge.mjs, rename for the new slug, update the NARRATIONS array, OUTPUT_DIR, and durations file path. Run from simple-narrated-slides/:
node scripts/generate-{slug}-audio-edge.mjs
This produces the MP3s and writes real durations to src/{slug}-durations.ts. See Edge TTS Guide for full details.
5
Preview Check at localhost:3001 in Remotion Studio.
6
Render
npx remotion render {CompositionId} {slug}-v1.mp4
7
Create wrapper HTML Copy byg-nuclear-plant.html as the template. Update the title, description, and MP4 src. Save as ephemeral-notebook/apps/byg-{slug}.html.
8
Deploy to gh-pages Use the gh-pages-deploy skill to push both the MP4 and wrapper HTML to notebooklm/byg-{slug}/.
9
Update the web app In behold-your-god.html, change the illustration's badge from "Coming Attraction" to "▶ Watch" and add the link to the wrapper page.
10
Update status Mark the illustration complete in project-definition.md and fill in the build time slots in this document.

💡 Future Web App Ideas

Branching Scenario
Drop the user into a scene — Palm Sunday, the crowd wants to make Jesus king — and let their choice reveal the irony. "Challenge, Choice, Consequence" cycle. Illustration 00 is the prime candidate. Can be extended to other illustrations as they're built.
+45% interaction rate
Connections Game
Group the 11 illustrations into hidden categories (e.g. "How God Destroys", "God's Law", "The Cross", "God's Character"). Users drag and drop to find the groupings. Engages pattern recognition and reinforces the book's thematic structure. Content is already in the knowledge base.
Scrollytelling Controversy Arc
A scroll-driven narrative through the great controversy: Lucifer's misrepresentation → Eden → Cross → Final Message → Vindication. Dynamic reveals and transitions tied to scroll position. Best suited for the dense theological overview.
+62% dwell time · +317% scroll depth
Wire Explorer/Quiz to Illustrations
Currently the Explorer and Quiz tabs run off standalone embedded content. Future: generate Explorer/Quiz content per-illustration so users can dive deeper into any specific video's argument after watching it.
