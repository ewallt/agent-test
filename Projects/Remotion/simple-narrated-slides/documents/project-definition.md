# Simple Narrated Slides — Project Definition

Dark-background slideshow videos with Edge TTS narration; each composition is a self-contained TSX file with per-bullet audio, used primarily as the build system for BYG illustration videos.

## Skills

- `simple-narrated-slides` — builds a new composition (TSX file, audio generation, Root.tsx registration, render). See `Projects/Remotion/simple-narrated-slides/skills/simple-narrated-slides.md`.
