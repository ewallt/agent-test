# Remotion Narrated Slides — Project Workflow

## Project Layout

```
agent-test/
  start-studio.js        ← dev server launcher (FOLDER constant lives here)
  render.js              ← render to MP4 (FOLDER constant lives here too)
  start-remotion.bat     ← alternative dev server launcher (SET FOLDER= at top)
  output/                ← rendered MP4s land here

  model-collapse/        ← the Remotion project (folder name set by FOLDER constant)
    src/
      Root.tsx           ← registers all compositions, computes total durations
      BattleOfAtlantic.tsx ← per-bullet audio composition (exports timing constants)
      Britain1940.tsx    ← per-slide audio composition
      atlantic-durations.ts ← AUTO-GENERATED: per-bullet durations (number[][])
      slide-durations.ts ← Britain1940 slide durations (number[])
      index.ts           ← Remotion entry point
    scripts/
      generate-atlantic-audio.mjs ← ElevenLabs: generates 16 MP3s + updates atlantic-durations.ts
      generate-audio.mjs          ← ElevenLabs: generates Britain1940 audio
    public/
      audio/
        atlantic/        ← title.mp3, s1b1.mp3 … s5b3.mp3
        title.mp3, slide-1.mp3 … slide-5.mp3  (Britain1940)
```

## The Pipeline (dependency chain)

```
Edit .tsx/.ts source files
        ↓
  webpack auto-recompiles (HMR) — check server logs for errors
        ↓
  Run audio generation script (needs ElevenLabs API key)
        ↓  produces MP3s
  Script measures durations → writes *-durations.ts
        ↓
  webpack recompiles with real durations
        ↓
  Preview in Remotion Studio to verify
        ↓
  node render.js <CompositionId>  →  output/<CompositionId>.mp4
```

**Never edit `*-durations.ts` manually** — they are auto-generated by the scripts.

## Two Audio Architectures

### Per-bullet (BattleOfAtlantic — the preferred pattern)
- One MP3 per bullet: `s{slide}b{bullet}.mp3` (16 files total: title + 5×3)
- Each bullet fires its own `<Sequence><Audio /></Sequence>` at an exact frame
- Bullet text springs in at the same frame as its audio starts
- Timing is structurally guaranteed — visual and audio cannot drift

### Per-slide (Britain1940 — older pattern)
- One MP3 per slide: `slide-{n}.mp3`
- Bullets stagger visually across the slide duration using a fraction of `audioPortion`
- Less precise — if narration changes length, bullets may misalign

**Prefer per-bullet for new compositions.**

## Timing Architecture (per-bullet)

Constants exported from `BattleOfAtlantic.tsx` (Root.tsx imports these):
```ts
SLIDE_INTRO_FRAMES  = 24   // silence before first bullet audio starts
BULLET_GAP_FRAMES   = 18   // silence between bullets
SLIDE_BUFFER_FRAMES = 45   // silence after last bullet before slide ends
```

Per-slide duration formula (used identically in both Root.tsx and BattleOfAtlantic.tsx):
```ts
slideDuration =
  SLIDE_INTRO_FRAMES
  + bullets.reduce((sum, dur) => sum + dur + BULLET_GAP_FRAMES, 0)
  + SLIDE_BUFFER_FRAMES
```

Root.tsx converts seconds → frames:
```ts
ATL_BULLET_FRAMES = ATLANTIC_BULLET_DURATIONS_S.map(
  bullets => bullets.map(s => Math.ceil(s * FPS))
)
```

Total composition duration:
```ts
ATL_TOTAL = TITLE_FRAMES + ATL_SLIDE_FRAMES.reduce((a, b) => a + b, 0)
```

## Commands

All run from `agent-test/` unless noted.

**Start dev server (preview):**
```powershell
node start-studio.js
```

**Generate audio + update durations (run from model-collapse/):**
```powershell
$env:ELEVENLABS_API_KEY="sk-..."
node scripts/generate-atlantic-audio.mjs
```

**Render to MP4:**
```powershell
node render.js BattleOfAtlantic
node render.js Britain1940
```

Output lands in `agent-test/output/<CompositionId>.mp4`.

- Progress bar: 4px at very bottom, accent colour, `zIndex: 20`
- Slide counter: top-right, `01 / 05` format
- Title card: animated corner brackets + expanding accent line
- Bullets: spring in from left (`translateX`), dot marker, accent colour

## Known Gotchas

1. **Stale server on port 3000** — if changes don't appear, an old `start-studio.js` process may still be running. Find it with `netstat -ano | findstr :3000`, then `Stop-Process -Id <PID> -Force`.

2. **`process.argv` pattern** — `start-studio.js` and `render.js` set `process.argv` then `require()` the Remotion CLI directly. This is intentional — it avoids needing `npx` or a global install.

3. **`FOLDER` in two places** — when renaming the project folder, update `const FOLDER` in both `start-studio.js` and `render.js`, plus `SET FOLDER=` in `start-remotion.bat`. The JSON files (`package.json`, `launch.json`, `settings.local.json`) need manual find-and-replace.

4. **Duration files are auto-generated** — `atlantic-durations.ts` is overwritten every time the generation script runs. Never edit it manually.

5. **Root.tsx and composition must use identical duration formula** — if you change timing constants in `BattleOfAtlantic.tsx`, the exports must update too, or Root.tsx will compute a different total than the composition expects.

6. **Britain1940 uses per-slide audio** — its `Slide` component reads `audio/slide-{n}.mp3`, not per-bullet files. `slide-durations.ts` holds `number[]` (flat), not `number[][]`.

## Adding a New Composition

1. Create `src/NewTopic.tsx` — follow `BattleOfAtlantic.tsx` as the template (per-bullet pattern)
2. Create `src/new-topic-durations.ts` — `number[][]` with placeholder values
3. Create `scripts/generate-new-topic-audio.mjs` — follow `generate-atlantic-audio.mjs`
4. Export timing constants from `NewTopic.tsx` (`SLIDE_INTRO_FRAMES` etc.)
5. Register in `Root.tsx`: import durations + constants, compute frames, add `<Composition>`
6. Run the generation script to produce real MP3s and durations
7. Render with `node render.js NewTopic`
