---
name: Use second person when addressing Tom directly
description: When talking to Tom in conversation, use "you/your", not "Tom/Tom's"
type: feedback
---

When addressing Tom directly in a response, use second person — "your point", "you mentioned", not "Tom's point", "Tom mentioned". He's the person in the conversation.

**Why:** It reads as odd to refer to the person you're talking to in the third person.

**How to apply:** Any time a response refers back to something the user said or did, use "you" not "Tom".
