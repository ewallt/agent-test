# Skill: Video Focus Strategy

## What This Covers
How to select sources and design focus angles to produce distinct, high-quality videos
from a multi-source notebook.

## Core Principle
Each video should cover a distinct thematic angle. One source per video, targeted with
`--source-ids` and `--focus`. This prevents cross-contamination and gives each video
a clear identity.

## Source Selection
After research import, review the source list and evaluate each source:
- Does this source have a clear, bounded scope?
- Is it meaningfully different from the other sources?
- Does it go deep enough on its topic to sustain a full video?

These are self-evaluation questions — decide internally and proceed. Do not ask Tom.

Prefer sources that are complementary rather than overlapping.

## Focus Angle Design
The `--focus` prompt is the equivalent of the pencil/prompt icon in the NotebookLM UI.
It directs what the video emphasizes.

**How strictly is it followed?**
Moderately. NotebookLM treats the focus prompt as a "scriptwriter" brief — it shapes
the story direction but does not enforce a checklist. If the prompt contains 3-4 distinct
constraints, later ones may be dropped. The AI prioritizes narrative over completeness.

**Key implication: keep focus prompts short and pointed.**
One clear angle per prompt. If you give it multiple things to cover, expect it to pick
the most narratively compelling one and run with it.

**Too vague**: "World War II"
**Too complex**: "Cover the causes, the spread, the mortality rate, the cures people tried, and the long-term aftermath"
**Good**: "Allied industrial superiority and the role of Soviet and American production in winning the war"
**Good**: "How the Black Death ended the medieval feudal order and empowered the peasant class"

Match each focus angle to its source — don't ask a source to cover something it doesn't contain.

**Source adherence:** High. NotebookLM stays within the selected source (`--source-ids`
is working), but generalizes the *tone* of the source rather than following the focus
prompt strictly. The source content shapes what stories are available; the focus prompt
shapes which story gets told.

## Example: "Why the Allies Won" — Overy
Suggested focus angles for 3 videos:
1. **Air power** — Allied strategic bombing, Luftwaffe decline, air superiority over Europe
2. **Industrial and economic power** — Soviet and US production capacity vs. German war economy
3. **Strategic and command decisions** — Allied coalition leadership vs. Hitler's strategic errors

Each of these maps to a distinct chapter cluster in Overy's argument and can stand alone.

## Queueing
Submit all video create commands without waiting between them. NotebookLM queues them.
Renders are LIFO (last submitted renders first) — order doesn't matter.

## Command Template
```
PYTHONIOENCODING=utf-8 nlm video create <notebook-id> --confirm \
  --format cinematic \
  --focus "<specific focus angle>" \
  --source-ids <source-id>
```

## Notes
- Always use `--format cinematic` — this must be passed explicitly; the CLI default is `explainer`
- `--source-ids` requires the full UUID — 8-char prefixes cause silent failures; get full IDs from `nlm source list <notebook-id>`
- `--style` is omitted unless Tom specifies one; cinematic videos use `auto_select` by default
- Render time: ~8-10 minutes per video
- Check status: `PYTHONIOENCODING=utf-8 nlm studio status <notebook-id>`
- Video titles are generated by NotebookLM independently — they reflect its own interpretation
  of the focus prompt, not the prompt text itself. Expect creative/catchy titles, not literal ones.
- Focus prompts are "scriptwriter" briefs, not scripts. One strong angle beats a list of constraints.
